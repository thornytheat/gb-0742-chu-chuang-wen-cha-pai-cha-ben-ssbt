# 字段与规则

## 图档、时刻和单位

| 字段 | 含义 |
|---|---|
| `probe` | 探头号，ASCII 字符串，保留前导零 |
| `observed`, `received` | 带时区偏移的 ISO 8601 整秒测量与收报时刻，按 UTC 比较 |
| `temp`, `temp_unit`, `temp_sigma` | 温度、温标 C/F/K、同温标的标准不确定度 |
| `rh`, `rh_unit`, `rh_sigma` | 湿度、单位 PCT/%/RATIO、同单位的标准不确定度；湿度允许缺值 |
| `memo` | 原始备注，可含逗号与引号内换行 |

采信使用 UTF-8 BOM 处理与 GB18030 回退。第二段可使用中文或重排的栏头。按物理起止行留证。每档首个栏头从记录账中扣除，其余空行与重栏仍入账。数据记录多列或少列会隔离，整档记录量不等于契约声明值会拒绝整批。

温度统一为 °C，华氏温度作减 32 后乘 5/9，华氏标准不确定度只乘 5/9。开尔文温标减 273.15，标准不确定度保持原尺度。相对湿度统一为 %RH，比例输入的读数和不确定度同乘 100。量值用 Decimal 记录四位小数，同量纲的正零与负零视为相等。`-`、空串、`N/A`、`NULL`、`未知` 为缺值。探头号和测量 UTC 是去重键，比较归一后的读数及不确定度。完全一致选最早收报再选最小物理行号，矛盾时整组隔离。迟报只打 `LATE_RECEIPT` 标记，收报早于测量则隔离。

## 部署和配准

- 部署、班次和柜时窗口均为 `[起点, 终点)`。部署按测量时刻查找。探头重复在位或同柜同层多探头在位会记录重叠区间，相关测点隔离。跨过重叠区间或迁移时刻的两条读数不能配对。
- 每个登记柜每小时有一个应监测柜时。上层读数所在小时是配对归属。下层可来自同班次内邻近小时，条件是同柜、时差不超阈值、上下部署在两次测量之间连续有效。
- 同柜按时间求解一对一配准。目标先最大化成对柜时，再最小化时差绝对值之和。允许同一柜时的多条上层进入候选，最多采用一条。相同代价的单条边优先使用更近小时中点的上层，随后用测量时刻、物理行号确定。全局同分按固定转移顺序选配对、跳过下层、跳过上层。
- 未配的柜时分为没有上层、没有兼容下层、兼容下层已分配三类。额外上层与未用下层单独登记，不改变图档采信账。

## 梯度、置信区间和异常段

垂直梯度为 `(上层读数 - 下层读数) / 层间距 m`。温度以 °C/m 表示，相对湿度以 %RH/m 表示。假定上下标准不确定度独立，区间半宽取 `1.96 × sqrt(σ上² + σ下²) / 层间距 m`。判级比较未按展示精度舍入的区间端点，区间和值对外展示三位小数。

| 区间情形 | 单项判级 |
|---|---|
| 整个区间严格高于正阈值或严格低于负阈值 | 异常 |
| 区间完整落在 `[-阈值, +阈值]` 内 | 稳定 |
| 区间与阈值相交且未落在安全区间内 | 跨阈值 |

任一指标支持明确异常则柜时异常，两项都稳定则柜时稳定，其他情况记缺证。连续异常按柜号与 UTC 小时合并。稳定、缺证及缺小时都会断段，达到配置的小时数才是持续异常。段尾为最后一个异常柜时的右边界。

## 账务与证据

- 应监测柜时数＝稳定＋异常＋缺证。另查应到键集合和实际键集合，报告缺、多、重复。
- 实收逻辑行＝采信＋隔离＋重复＋空行＋重复栏头。声明数据量只含前三类。
- 报警按柜号和时刻落入柜时，相同持续段最早一单核销。其他结果区分重复、瞬时异常、缺证、稳定时报警、超班次、未知柜号。无已配工单的持续段单列。
- 归卷键根据原档、契约 SHA-256 与规则版次生成。清单、结果、固定输入在同一次存储事务提交。重跑复算固定原档，验证结果摘要与输入摘要。导出 JSON 包内含原始图档 Base64、契约、输入与结果摘要和逐阶段证据。

## 支持范围

使用仓内登记样例。单批最多 8 柜、168 个小时、4,000 条记录，CSV 上限 1 MiB。部署为独立的上下层测点，不接入采集推送。区间近似假定上下读数误差独立，未估计长期相关漂移或空间协方差。数值差用确定的监测阈值作复判。
